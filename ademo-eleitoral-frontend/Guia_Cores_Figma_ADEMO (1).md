# Guia de Cores — Sistema de Votação Eleitoral ADEMO

Documento preparado para facilitar a criação de estilos/variáveis de cor no Figma.

## 1. Regras gerais de uso

- O vermelho da ADEMO deve ser usado como cor institucional, item activo do menu e acções perigosas.
- Botões de acção normal devem usar azul.
- Estados positivos devem usar verde.
- Avisos devem usar âmbar/amarelo escuro.
- Erros, eliminar, cancelar, desactivar e desqualificar devem usar vermelho.
- Não depender apenas da cor: usar sempre texto e, quando possível, ícone.

## 11. Texto rápido para justificar no documento

A paleta proposta mantém a identidade visual da ADEMO, mas adapta o uso das cores para melhorar a acessibilidade e a experiência de utilização. O vermelho institucional é mantido em elementos de marca, item activo do menu e acções críticas, enquanto o azul passa a representar acções principais e seguras, como entrar, guardar, continuar e votar. O verde é reservado para estados positivos, o âmbar para avisos e o vermelho para erros ou acções perigosas. Esta separação facilita a compreensão do sistema, especialmente para utilizadores idosos ou com baixa visão.
